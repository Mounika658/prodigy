1.Caesar Cipher Encryption & Decryption

This project implements the Caesar Cipher Algorithm in Python, allowing users to securely encrypt and decrypt text messages using a customizable shift value. The program takes user input, applies the Caesar Cipher technique, and generates the corresponding encrypted or decrypted output.

2.Features

Encrypt plain text messages
Decrypt encrypted messages
User-defined shift value
Handles both uppercase and lowercase letters
Simple and beginner-friendly Python implementation

3.Technologies Used

Python 3

tkinter

4.Learning Outcomes

Understanding basic cryptography concepts
Working with string manipulation in Python
Implementing encryption and decryption algorithms
